# UI Preferences

Back to [[My Preferences]]

**Likes**
- Clean UI with cool, **fluid animations**.
- Hand-drawn icons; labels that change with what a button does right now.
- Menus with tabs (inventory, map, achievements, settings).
- Maps that show the whole world at once, tell you about a place when you click it, and uncover as you explore.
- Waypoints only for the destination you picked.
- A loading screen that really waits for everything, with tips, and that also covers teleports (fast travel).
- Lots of smooth UI animations, especially in menus and on the speedometer (2026-10-20).
- On mobile: no screen clutter. Buttons double as cooldowns; extra buttons only show when they're needed (2026-10-20).

**Dislikes**
- **"AI looking" UI**: generic panels, emoji icons, glow everywhere.
- Text outlines that hang on screen after the text fades.
- Waypoint markers everywhere at once.
- UI elements sitting on top of each other.
